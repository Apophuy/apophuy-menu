# Changelog

All notable changes to this project will be documented in this file. The format
is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and the
project uses [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Added

- Plasma 6 application categories and launching through the native Kicker model
- Per-instance native Favorites with add and remove controls
- KRunner-powered search with keyboard navigation and two-stage Escape behavior
- Grouped Session and Power menus backed by Plasma's native system-action model
- Follow System, Light, and Dark appearance modes
- Original pseudo-3D and flat Apophuy Penguin icons with color presets and a
  custom accent option
- English and Russian gettext catalogs
- Static package, QML, translation, and runtime model checks
- Current-user install, update, uninstall, and release packaging scripts

### Compatibility

- Targeted Debian 13, KDE Plasma 6.3, Qt 6.8, KDE Frameworks 6.13, and Wayland

### Verification pending

- Suspend/resume recovery in the real Wayland panel
- Successful native system-action invocation and single popup closure
- Curated release screenshots
